# Automated-Data-Processing-Extraction-and-Documentation-System

An end-to-end business automation system that transforms raw sales data into a professional, AI-powered business report.

The system automatically collects sales data from Google Sheets, processes and validates the data using Python and Pandas, generates verified KPIs and visualizations, uses Gemini to interpret the results and provide actionable recommendations, and produces a professional PDF report that is simultaneously stored in Google Drive and delivered by email.

## Overview

Businesses often receive sales data that requires manual cleaning, analysis, reporting, and distribution. This workflow automates the entire process.

Instead of manually:

* Cleaning spreadsheets
* Calculating sales KPIs
* Creating charts
* Interpreting business performance
* Writing management summaries
* Creating PDF reports
* Uploading reports to cloud storage
* Emailing stakeholders

the system performs the entire workflow automatically.

## Key Features

### Automated Data Processing

The Python backend receives sales records through a REST API and performs automated data preparation using Pandas.

The processing pipeline can:

* Standardize column names
* Remove duplicate records
* Parse and validate dates
* Convert numeric fields
* Standardize text values
* Handle missing regions
* Handle missing unit prices
* Handle missing quantities
* Correct invalid quantities
* Handle missing discounts
* Recalculate sales values
* Remove invalid dates
* Track data-quality corrections

### Verified Business KPIs

The Python processing layer calculates deterministic business metrics including:

* Total Sales
* Total Orders
* Total Units Sold
* Average Order Value
* Average Discount
* Top Product
* Top Region
* Top Category
* Top Salesperson
* Reporting Period

The numerical analysis is performed by Python rather than AI to ensure that the figures used in the report are reproducible and verifiable.

### Automated Visualizations

The system generates business-performance charts including:

* Sales by Product
* Sales by Region
* Sales by Category
* Daily Sales Trend

These visualizations can be incorporated into the final business report.

### AI-Powered Business Analysis

Gemini receives the verified analytics generated by the Python processing layer.

The AI generates:

* Executive Summary
* Key Sales Insights
* Top-Performer Analysis
* Data Quality Summary
* Actionable Business Recommendations

The AI is instructed to use only the verified analytics supplied by the Python system rather than independently inventing or recalculating numerical results.

### Automated PDF Reporting

The AI-generated analysis and verified business metrics are formatted into a professional PDF report.

The report can contain:

* Report title
* Reporting period
* KPI summary
* Executive summary
* Key insights
* Top performers
* Data-quality information
* Business recommendations
* Data visualizations

### Automated Distribution

Once the PDF is generated, Make routes the same report to two destinations simultaneously:

```text
                    PDF
                     │
                  Router
                 /      \
                ▼        ▼
       Google Drive     Gmail
        Store Report   Send Report
```

This eliminates the need to manually download, upload, and email reports.

## API

The Python backend exposes a REST endpoint:

```text
POST /api/process-sales
```

Example request:

```json
{
  "records": [
    {
      "Order_ID": "ORD001",
      "Date": "2026-01-05",
      "Customer_ID": "C001",
      "Product": "Headphones",
      "Category": "Accessories",
      "Region": "North",
      "Quantity": 2,
      "Unit_Price": 121.41,
      "Discount": 0.05,
      "Sales": 230.68,
      "Payment_Method": "Credit Card",
      "Salesperson": "Olivia"
    }
  ]

```

The API processes the records and returns structured analytics including KPIs, data-quality statistics, top performers, aggregated sales information, reporting dates, and chart locations.

## Data Processing Architecture

The system intentionally separates **deterministic analytics** from **AI interpretation**.

### Python handles:

```text
Raw Data
   ↓
Cleaning
   ↓
Validation
   ↓
Calculations
   ↓
KPIs
   ↓
Charts
```

### Gemini handles:

```text
Verified Analytics
        ↓
Business Interpretation
        ↓
Insights
        ↓
Recommendations
```

This separation helps prevent an AI model from becoming the source of truth for numerical business metrics.

## Example Use Case

A company maintains its sales records in Google Sheets.

At the end of a reporting period, the workflow can automatically:

1. Retrieve the sales records.
2. Send the data to the Python processing API.
3. Clean and validate the dataset.
4. Calculate verified sales KPIs.
5. Generate performance charts.
6. Send the analytics to Gemini.
7. Generate business insights and recommendations.
8. Build a professional PDF report.
9. Store the report in Google Drive.
10. Email the report to stakeholders.

The result is an automated reporting pipeline requiring minimal manual intervention.

## Why This Architecture?

The system is designed around a clear separation of responsibilities:

**Make** handles workflow orchestration and integrations.

**Python/Pandas** handles data cleaning, validation, calculations, and visualization.

**Gemini** handles natural-language interpretation and recommendations.

**PDF Generator API** handles professional document generation.

**Google Drive and Gmail** handle report storage and distribution.

This makes the system easier to maintain and allows individual components to be replaced or extended without redesigning the entire workflow.
